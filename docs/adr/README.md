# Architecture Decision Records

This directory contains short ADRs for accepted architectural decisions.

Each ADR uses only:

- Context
- Decision
- Consequences

ADRs 0004 and 0008 are retained for history and explicitly superseded by ADR
0009, which also supersedes ADR 0001's original subagent-type mutation
mechanism. ADRs 0001 and 0005 otherwise record the current interception and
picker IPC boundaries.
